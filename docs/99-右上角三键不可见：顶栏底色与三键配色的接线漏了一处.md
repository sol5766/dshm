# 99 · 右上角三键不可见：顶栏底色与三键配色的接线漏了一处

> 用户原话：「APP 右上角三个按钮消失不见，鼠标碰过去只有一个关闭」。
> 本文记真根因、修法、**客观判据**（像素）与防复发门禁 —— 这类"小问题反复出"，
> 根子几乎总是**同一个语义有两条通道、而某条通道漏接了**。

## 1. 症状与初判

- 三键（全屏/最小化/关闭）**看不见**；鼠标扫过只有「关闭」现形（它有 hover 底色）。
- 布局树里三键**存在**（`uitest dumpLayout` 能取到"全屏"节点）⇒ 不是"没注册/没创建"，
  而是**画出来了但看不见** ⇒ 方向立刻从"按钮没了"转到"**颜色对比度**"。

## 2. 真根因（代码 + 像素双证据）

- 截图竖剖面：应用顶栏（含三键区）整条是 `rgb(21,21,23) ≈ #151517`；三键区 8848 个采样像素
  **全暗、0 个亮像素**；
- `EntryAbility.ets` 在创建窗口时把三键**强制**设为 `COLOR_MODE_LIGHT`（= 深色图标）——
  那是给早期"**恒白底**顶栏"配的口径；
- 顶栏底色有**两条通道**：
  ① 主通道：web 主题桥（`THEME_SHIM_JS` → `themeBridge` → `applySystemBarTheme`）；
  ② 兜底通道：DOM 探针（~10s 一轮）→ `applyTopBarTheme`；
- **三键配色只挂在②上**，主通道**只翻顶栏、从不碰三键** ⇒ 深色外观下顶栏变 `#151517`，
  三键仍是被强制的深色图标 ⇒ **黑底黑键**（只有「关闭」因 hover 有底色才现形）。

## 3. 修法（最小改动，+39 / −12，只动 `WebApp.ets`）

1. 新增 `applyDecorButtonMode(mode)`：三键配色**跟随顶栏底色**（深底浅键 / 浅底深键）；
2. 在 `applySystemBarTheme`（主通道）里调用它 ⇒ 两条通道共用同一口径；
   `applyTopBarTheme` 里那段内联实现改为**复用**，消除双份口径；
3. 顺带修隐患：窗口未就绪时也会把幂等闸门（`systemBarApplied`）锁死 ⇒ 窗口就绪后**永不补齐**
   三键配色。现在该路径清闸门（与既有失败路径一致）。

## 4. 真机判据（客观，不靠肉眼）

| 时点 | 三键区采样（窗口右上角） | 结论 |
|---|---|---|
| 修复前 | 深 8848 / 中 0 / **亮 0**，主色 `rgb(16,16,16)` | ❌ 全暗 ⇒ 不可见 |
| 修复后 | 深 8959 / 中 55 / **亮 114**（`rgb(208,208,208)` 等浅色笔画） | ✅ 深底上有浅色图标 ⇒ 可见 |

覆盖安装（`hdc install -r`，exit 0）：`home` 指纹 links 13→13 **未减少**、
核心树 `+dshm.6`、`exec 探测 8/8`、`Host HTTP 已就绪`。
另：`workspaceFiles/readBytes` 的**取消数自修复以来始终冻结**（149），证明预览链路未被牵动。

## 5. 防复发（本次的"系统性答案"）

新增门禁 `tools/check-decor-button-mode.mjs`（已进 `AGENTS.md` 必跑列表与 CI）：

- 9 条**结构判据**：主通道必须调用三键配色；`setDecorButtonStyle` **只允许出现在一个方法里**；
  兜底通道复用同一方法；主题桥没被改道；未就绪时不得锁死幂等闸门…
- **自带对照臂**：把主通道那次调用删掉 ⇒ 门禁**如期变红**（`8 passed / 1 failed`）。
  没有对照臂的结构门禁极易退化成"恒真摆设"，本仓的 `check-*-jitless` 系列同理。

## 6. 教训

1. **"按钮消失"先分清"没画"还是"看不见"**：布局树能取到节点 + 像素全暗 ⇒ 立刻锁定**对比度**，
   不必在"注册/创建"上绕圈。
2. **同一语义只允许一条设置路径**：顶栏底色有两条通道时，依赖它的**派生表现**（三键配色）必须挂在
   **两条通道都经过的那个**函数上（这里是 `applySystemBarTheme`），而不是其中一条。
3. **幂等闸门别锁在"未真正应用"的状态上**：失败/未就绪时必须放闸，否则"以后再补"永远补不上。
4. **模型读不了图时，用像素统计当眼睛**：按窗口矩形裁区、统计亮度直方图，能得到可复核的
   修复前/后判据（本例 0 → 114 个亮像素）。

# DSHM v1.1.0 发布说明（2026-09-30 至 2026-10-05）

> 本文同时作为 GitHub Release `v1.1.0` 的发布正文（<https://github.com/sol5766/dshm/releases/tag/v1.1.0>）。
> 配套的侧载包与校验见 `dist/sideload/`（不入库）。


本版本汇总 2026-09-30 以来的修复与增强，主要包含六个方面：**问题修复**、**侧边栏文件预览**、**终端接入**、**插件与 Node.js 诊断**、**PTC 运行能力**、**端侧核心升级**。

## 一、问题修复

- **选择器交互**（GitHub #3）：工作区选择器在「成功但有代价」时给出提示；目录选择器「换路径」改经 emitter 上报壳层（`71c8cba`、`1cfd56c`）。
- **托盘与退出**：托盘按官方行为重做——运行时挂图标、左键唤回主窗、右键使用系统菜单（`ab996b8`）；修复托盘幂等回归（重复挂载会摘掉仍活着的图标）（`5b7d47d`）；系统「关闭窗口」回到官方语义，即退出应用（`ecd4644`、`b25f47f`）。
- **窗口外观**：修复右上角三键（全屏/最小化/关闭）不可见的问题——顶栏底色与三键配色改为同源判定（`0d118a9`）。
- **宿主稳定性**：修复平台门放行后 `process.report.getReport()` 导致冷启动阻塞约 62 秒（`5f27b18`）；收敛宿主侧三项缺陷及 jitless 下的网络与终端适配（`5bbfe6b`、`1257daf`）。

## 二、侧边栏文件预览

- **Office 文档**：doc / docx / ppt / pptx / xls / xlsx / odt / ods / odp 共 9 项改由插件调用**系统预览窗**打开（`cadb811`），认领范围收敛为 Office 专用（`1e30b01`、`a04cfac`）。
- **读取失败根因修复**：宿主 undici 垫片不识别 `Response(FormData)`，导致带附件的 RPC 响应体为空（客户端表现为 `ERR_EMPTY_RESPONSE(-324)`）；修复后读取的取消数自修复起零新增（`1e30b01`）。
- **内联渲染**：文本、图片、PDF、HTML 等格式仍由内置渲染器在侧栏直接展示，点击即读。

## 三、终端接入

- 沙箱内工具链落地：python3.12、git（含 git-core / git-remote-http / git-ls-remote）、ripgrep、ash、bash 可用；覆盖安装后自检的 exec 探测 **8/8 通过**（`place-toolchain`、`assert-exec-fix`）。
- jitless 运行时下的网络与终端适配（`5bbfe6b`）；内置技能补充 `ohos-shell` 等（`aa69813`）。

## 四、插件与 Node.js 诊断

- **插件与工具**：文件删除、非 chmod 写入、工作区认领、Office 系统预览等插件随包发布；新增核心树插件扫描工具（`scan-core-plugins`）。
- **诊断能力**：同步调用环 `SYNC-RING` / `SYNC-WARN` / `SYNC-COUNT` 直接点名阻塞事件循环的同步调用（`fd1e10f`、`6c8c8fe`）；心跳线程 `HB` 区分「主线程被挡」与「进程被冻结」（`86d9ecd`）；V8 CPU 采样定位停顿期间执行内容（`2e0bf6f`）；accept 轨迹与事件循环看门狗（`4f03ddd`）；逐跳 `IN-DONE` 耗时与插件日志时间戳（`433a943`）；诊断默认开启（`8854369`）。

## 五、PTC 运行能力

- PTC 运行时改为**同进程纯 JS 实现**，不再依赖外部运行时，jitless 下可直接运行（`b4bdcb5`）。
- TypeScript 擦除器纯 JS 化（81 条断言，含 wasm 陷阱用例）；「换实现」的三处接线（profile ↔ pack-core ↔ 核心树）自洽，由 `check-ptc-ts-strip` / `check-ptc-runtime-inproc` / `check-ptc-wiring` 守护。
- jitless 补齐下沉到 worker：插件自建 worker 线程同样可用。

## 六、端侧核心升级

- 端侧核心升级至 **0.2.1-alpha.1**（兼容契约连续第四次零漂移），本版运行 `0.2.1-alpha.1+dshm.6`（`000e8d3`）。
- 端侧注入补丁扩充至 **19 处**并新增 **1 处撤除守卫**，全部纳入门禁校验（`ee92b44`、`16378d9`、`7a03ffb`）。
- 核心版本采用 semver 构建元数据（`+dshm.<n>`）标注，端侧目录与自检输出可直接判读运行版本。

## 升级方式

- 覆盖安装（**请勿卸载**，卸载将丢失会话、插件与工作区）：

  `hdc install -r DSHM-1.1.0-core0.2.1-alpha.1+dshm.6-arm64-signed.hap`

- 应用版本 **1.1.0**（versionCode 1010000）；端侧核心 **0.2.1-alpha.1+dshm.6**；完整性校验见同目录 `SHA256SUMS.txt`。

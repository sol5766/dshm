# DSHM v1.1.0 发布说明（2026-09-30 至 2026-10-05）

> 本文同时作为 GitHub Release `v1.1.0` 的发布正文（<https://github.com/sol5766/dshm/releases/tag/v1.1.0>）。
> 与之配套的侧载包与校验见 `dist/sideload/`（不入库）。


本次发布聚焦四件事：**问题单修复并入主线**、**终端（Shell）接入**、**插件与 Node.js 诊断能力**、**PTC「run code」在端侧可用**。

## 一、问题单修复并入主线

- GitHub #3 收口：工作区选择器在「成功但有代价」时给出提示；目录选择器「换路径」改经 emitter 上报壳层（`71c8cba`、`1cfd56c`）。
- 侧边栏 Office 预览从「点击读不到文件」修到可用：Office 文档改走系统预览窗（`cadb811`），认领范围收敛为 Office 9 项（`1e30b01`、`a04cfac`）。
- 托盘与窗口：托盘按官方行为重做（运行时挂图标 / 左键唤回 / 右键使用系统菜单）（`ab996b8`）；修复托盘幂等回归（`5b7d47d`）；修复窗口右上角三键不可见（`0d118a9`）。
- 系统「关闭窗口」回到官方行为 = 退出应用，不再拦截为最小化到后台（`ecd4644`、`b25f47f`）。

## 二、终端（Shell）接入

- 沙箱内工具链落地：python3.12、git（含 git-core / git-remote-http / git-ls-remote）、ripgrep、ash、bash 全部可用；覆盖安装后自检的 exec 探测 **8/8 通过**（`place-toolchain`、`assert-exec-fix`）。
- jitless 运行时下的网络与终端适配（`5bbfe6b`）；内置技能补充 `ohos-shell` 等（`aa69813`）。

## 三、插件与 Node.js 诊断

- 插件与工具：文件删除、非 chmod 写入、工作区认领、Office 系统预览等插件随包发布；新增核心树插件扫描工具（`scan-core-plugins`）。
- 宿主侧诊断读数成体系：同步调用环 `SYNC-RING` / `SYNC-WARN` / `SYNC-COUNT` 直接点名挡住事件循环的那次同步调用（`fd1e10f`、`6c8c8fe`）；心跳线程 `HB` 区分「主线程被挡」与「进程被冻住」（`86d9ecd`）；V8 CPU 采样点名停顿期间在执行什么（`2e0bf6f`）；accept 轨迹与事件循环看门狗（`4f03ddd`）；逐跳 `IN-DONE` 耗时与插件日志时间戳（`433a943`）；诊断默认开启（`8854369`）。

## 四、PTC「run code」在端侧可用

- PTC 运行时改为**同进程纯 JS 实现**，不再依赖外部运行时；在 jitless 下可直接运行（`b4bdcb5`）。
- TypeScript 擦除器纯 JS 化（81 条断言，含 wasm 陷阱用例）；「换实现」的三处接线（profile ↔ pack-core ↔ 核心树）自洽，均有门禁守护（`check-ptc-ts-strip`、`check-ptc-runtime-inproc`、`check-ptc-wiring`）。
- jitless 补齐下沉到 worker：插件自建 worker 线程同样可用。

## 升级方式

- 覆盖安装（**请勿卸载**，卸载会丢失会话 / 插件 / 工作区）：

  `hdc install -r DSHM-1.1.0-core0.2.1-alpha.1+dshm.6-arm64-signed.hap`

- 应用版本 **1.1.0**（versionCode 1010000）；端侧核心 **0.2.1-alpha.1+dshm.6**；
- 完整性校验见同目录 `SHA256SUMS.txt`。

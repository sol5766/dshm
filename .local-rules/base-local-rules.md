# 本地规则库基础规则

## 1. 目的

本地规则库用于承接陌生环境中的实测信息，避免把每台机器的路径、设备 target 和命令结果写回共享规则库。

## 2. 优先级

1. 用户当前明确指令。
2. 更深层 `AGENTS.md`。
3. 根目录 `AGENTS.md` 和共享 `.rules/`。
4. `.local-rules/*.local.md` 中的本机事实。

本机事实只覆盖环境路径、设备连接、命令可用性、构建产物位置等事实判断，不覆盖共享架构规则和代码规范。

## 3. 允许自动写入的范围

- 新探测到的 SDK / IDE / Hvigor / HDC 路径。
- 新探测到的设备 target 和设备 API 版本。
- 已实测成功或失败的本机命令。
- 本机特有错误及其非破坏性规避方式。

## 4. 禁止写入的范围

- 密码、token、证书口令、私钥、账号。
- 未验证的猜测。
- 单次任务的业务结论。
- 可以沉淀到共享规则库的跨机器通用规范。

## 5. 推荐条目格式

```markdown
## YYYY-MM-DD 标题

**适用范围**：当前机器 / 当前工作区 / 当前设备  
**验证命令**：`...`  
**结果**：...  
**结论**：...  
**验证状态**：已实测 / 待复核  
```

如果条目会影响构建、安装、运行或调试命令，必须同时记录失败命令和失败原因，避免后续 Agent 重复试错。

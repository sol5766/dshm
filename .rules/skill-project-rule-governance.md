# skill: 项目规则治理

适用：`AGENTS.md` / `.agent-rules/` 读写；发现跨项目通用模式；记录持续性用户偏好。

## 分层

- 共享 `AGENTS.md` 与 `.rules/`：跨项目通用规则，仅开发者触发更新流程。
- 项目/App 专属规则与 Harness：写入 `.agent-rules/`，Agent 可按证据自动收集、更新、执行。
- 本机事实：写入 `.local-rules/*.local.md`，不回写 `.rules/`。

## 证据标准

- 规则须有可复现的「触发条件 + 标准做法 + 检查点」，不一事一议。
- 新增规则前先判断是否跨模块复用；只为一处问题写的规则不沉淀。

# App Agent Rule Registry

This directory contains App-specific guidance that supplements `AGENTS.md`.

Read `project-rules.md` before source changes and apply every `active` entry. Read `preferences.local.md` when it exists; it is local, non-sensitive, and cannot override user instructions, framework requirements, or active project rules.

| File | Purpose | Commit policy |
|------|---------|---------------|
| `project-rules.md` | Verified App architecture, product, quality, and delivery rules | Commit |
| `preferences.local.md` | Current user's durable, non-sensitive project preferences | Do not commit |
| `preferences.local.example.md` | Format example only | Commit |

Use the NGF project-rule-governance skill to create, revise, promote, deprecate, or remove entries. Candidates are research notes only and must not constrain implementation.
